# SIGNED365 · Web Evolution V6 (primera página interna)

- `index.html`: home V5 con enlace a la nueva página y anuncio compartido.
- `pginter/facturacion-electronica.html`: página interna basada en el wireframe adjunto.
- `css/internas.css` y `js/internas.js`: estilos y funciones de páginas internas.
- `js/announcement-shared.js`: **única configuración del anuncio** para home e internas (imagen, texto, enlace, retraso).
- `assets/anuncio-importante.svg`: imagen compartida del anuncio.
- `css/` y `js/`: archivos V5 conservados; `js/announcement.js` mantiene la apertura/cierre.

Para probar: abrir `index.html` o `pginter/facturacion-electronica.html` en un navegador. La carga de fuentes, Bootstrap, imágenes de placehold.co y enlaces externos requiere conexión a Internet.

Los textos comerciales de la nueva página son propuestas de maquetación sujetas a aprobación. Los enlaces de demo y otras soluciones son provisionales. El anuncio se muestra una vez por sesión y puede reabrirse desde la campana. No incluye backend ni modifica la aplicación SIGNED365.
